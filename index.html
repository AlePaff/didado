¿Tiene una vieja computadora en desuso?

 

Solicitamos cualquier elemento viejo funcionando que tenga en desuso:
gabinete, placa madre, placa de video, placa de sonido, placa de red, módem,
memoria, disquetera, ZIP, disco rígido, disco sólido, lectora y grabadora de CD,
DVD, Blu-ray, teclado, mouse, parlantes, monitor, impresora, escáner, disipador,
ventilador, cables; procesador 286, 386, 486, 586; AMD K5, K6, Athlon, Duron,
Sempron, Phenom, Fusion, FX, APU, Ryzen 3, 5, 7, 9, Threadripper, Pro, Athlon Pro,
EYPC; Intel Atom, Celeron, Pentium, Core Duo, Core 2, Core 2 Quad,
Dual Core, Core m3, i3, i5, i7, i9, X, Xeon; todo-en-uno,
notebook, netbook, ultrabook, tablet, ebook, etc.

Con estos componentes armamos computadoras y las entregamos
a instituciones educativas que no las pueden costear.
